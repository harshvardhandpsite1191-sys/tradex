# AI-QROS Frontend

Next.js dashboard application with 8 intelligence dashboards.

## Dashboards
1. Market Intelligence — Phase 10, 11, 12
2. Trade Center — Phase 19
3. Forecast Center — Phase 15
4. Liquidity Intelligence — Phase 5, 13
5. Options Intelligence — Phase 2, 4
6. Research Laboratory — Phase 6, 7, 8, 9
7. Historical Replay — Phase 21
8. Performance Center — Phase 24

## Running
```bash
npm install
npm run dev
```

## Environment
```
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_WS_URL=ws://localhost:8000
```
